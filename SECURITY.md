# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/DFXswiss/wdk-protocol-fiat-dfx/security/advisories/new).

Do not open a public issue that contains an exploit, a session URL, a bearer
token, a signature, a private key, a seed phrase, or personal data.

Include the affected version when one is published, the runtime, what you
expected, what happened, and the impact.

The module source is not on the default branch yet. A report about that
future package still belongs here.
